#	Requirements
		+	Java Runtime Environment (JRE) 21 or higher installed on the system
		+	Command line access (Terminal / Command Prompt / PowerShell)
	
========================================================================================================================

#	How to Run

		1.	Place the file DiskScheduling-1.0-SNAPSHOT.jar in any directory
		2.	Open a terminal or command prompt in that directory
		3.	Execute the following command (without quotes):
				"java -jar DiskScheduling-1.0-SNAPSHOT.jar"
		4.	The application window will launch

========================================================================================================================

#	Notes
	
		+	Ensure that Java is properly installed and added to system PATH
		+	To verify installation, run (Without quotes):
				"java --version"
		+	If the command is not recognized, install Java and restart the terminal
	
========================================================================================================================

#	Conclusion

	This application provides a graphical simulation of various disk scheduling algorithms. 
	It enables users to input requests, select algorithms, and visualize disk head movement, 
	offering a practical understanding of scheduling strategies and their efficiency.
